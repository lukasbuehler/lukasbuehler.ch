Deep Learning Blocks is a visual way to learn the basics of deep learning: building a neural network with toy blocks.

Inspired by “Baby’s First Deep Neural Network,” it represents layers, transformations, and data flow as colourful, draggable blocks connected by arrows. Learners arrange and connect pieces on a canvas to explore how a network is assembled and how information moves through it.

The starting point is intuition. Before getting into the mathematics or writing code, you can play with the structure and see how the pieces relate to one another.

The ambition is to grow this into a place to experiment with real models and learning behaviour, while keeping that approachable, hands-on starting point.
